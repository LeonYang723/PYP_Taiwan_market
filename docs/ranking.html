商品排行

依期間排名的商品預估銷量、價格與尺寸。可用下方「賣家」下拉選單篩選——之後追蹤的賣場變多時，這裡會自動列出所有賣家可以切換。

尚無資料。 這個系統剛設置好，還沒有任何快照資料。請先填寫「PYP蝦皮市場手動蒐集表.xlsx」， 再用 scripts/import_manual_products.py 匯入，接著執行 scripts/build_reports.py 產生報表。
提醒： 以下部分銷量估計值標示了 偏低估計，代表系統在該期間開始前還沒開始追蹤這項商品， 估計值可能低於實際銷量。詳見 README 的計算方式說明。
