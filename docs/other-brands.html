其他品牌

同一批賣場裡，跟 PYP 同類別（卡套/卡磚/卡冊/收納盒等）但不是 PYP 品牌的商品（例如 DEI DOW）。 用來看 PYP 在同一個賣場、同一個商品類別裡，銷量與價格跟其他品牌比起來如何。 這裡的資料不是 PYP 商品，不會算進「總覽」「商品排行」「商品資料」三頁的 PYP 銷量統計裡。

尚無「其他品牌商品」資料。 請先在「PYP蝦皮市場手動蒐集表.xlsx」的「其他品牌商品」工作表填寫資料， 再用 scripts/import_other_brands.py 匯入，接著執行 scripts/build_reports.py 產生報表。
提醒： 以下部分銷量估計值標示了 偏低估計，代表系統在該期間開始前還沒開始追蹤這項商品， 估計值可能低於實際銷量。詳見 README 的計算方式說明。
